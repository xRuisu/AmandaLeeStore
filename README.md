# Amanda Lee Soaps & Bubbles

A collaborative e-commerce website project for **Amanda Lee Soaps & Bubbles**, a handmade soap business.

This project is being built as both a real storefront concept and a learning-focused development project. The goal is to create a clean, friendly shopping experience while practicing collaborative software development, Git/GitHub workflows, frontend design, backend development, and e-commerce concepts.

> **Project Status:** Early Development / Prototype

---

## Project Goals

The website is intended to eventually support:

- Custom branded storefront
- Product listings and product details
- Shopping cart functionality
- Inventory tracking
- Customer accounts and login
- Checkout and payment integration
- Digital and printable receipts
- Order history
- Shipping label generation
- Administrative tools for products, stock, and orders

The project will be developed incrementally rather than implementing every feature at once.
